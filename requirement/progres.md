# Progres — AI Job Search Assistant

**Versi:** 0.2 · **Pembaruan:** 8 November 2026 · **Status:** rancangan hasil review

## Sudah dilakukan

- Mempelajari struktur dokumentasi `requirement` pada FarmaGO sebagai acuan pemisahan dokumen.
- Memeriksa README dan bagian source inti dari dua repo rujukan secara statis, lalu mencatat snapshot dan keterbatasannya.
- Menyusun draf kebutuhan produk, teknis, alur, desain, data, API, aturan bisnis, agent, rencana implementasi, pengujian, operasi, dan keputusan terbuka.
- Menyelaraskan kontrak provisioning, impor/pengiriman manual, snapshot formulir, bukti rekonsiliasi, kuota, ekspor/purge dan penahanan setelah restore.
- Memetakan 16 kebutuhan produk ke backlog dan 54 skenario UAT pada rencana implementasi.

## Belum dilakukan

- Menentukan repository tujuan, visibility, scope pilot, source yang diizinkan, provider dan kebijakan retensi.
- Menggabungkan source code, menulis aplikasi, migration, image container, atau konfigurasi CI.
- Mengakses akun portal pengguna, mengirim lamaran/email, melakukan panggilan model dengan data pribadi, atau menguji integrasi live.
- Menjalankan unit/integration/E2E, pentest, live UAT, backup atau restore aplikasi; skenario dalam test plan masih rencana.

## Langkah berikutnya

Tetapkan repo tujuan, cakupan P0, sumber awal, provider, dan retensi melalui [Decision Register](14-Decision-Register.md). Setelah discovery, ikuti urutan fase dan gerbang pengujian pada [Implementation Plan](08-IPD-Implementation-Plan.md). Catat bukti implementasi dan versi commit pada pembaruan progres berikutnya.
